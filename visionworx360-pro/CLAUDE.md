# CLAUDE.md

Read [AGENTS.md](AGENTS.md) first — its guardrails are binding.

- Commands: `bun install --frozen-lockfile`, `bun run typecheck`, `bun run test`,
  `bun run test:integration` (Docker + psql), `bun run build`,
  `bun run check:bundle-safety`. Details in `docs/DEVELOPMENT.md`.
- Never run the app or tests against the legacy Lovable production Supabase
  project; configuration fails closed by design — keep it that way.
- Database changes go in new files under `supabase/migrations/` (never edit an
  applied migration). Regenerate `src/integrations/supabase/types.ts` from a
  migrated database rather than editing it by hand.
- `src/routeTree.gen.ts` is generated by the TanStack Router plugin on build/dev.
- Lovable-coupled code is inventoried in `docs/LOVABLE_DEPENDENCIES.md`.
